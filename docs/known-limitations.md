### 1. Відомі дефекти (Known Defects)

* **Хардкод адреси бекенду** Використовується фіксований URL `http://127.0.0.1:8000`. На реальному фізичному пристрої або в стандартному Android Emulator (де потрібен `10.0.2.2` або IP хоста) запити завершуються помилкою підключення.
* **Примітивний парсинг у Fallback-рушії**
  * Евристика `local_analyze` жорстко прив'язує час нагадувань до `10:00` або `now + 3 години`, ігноруючи конкретно зазначений у тексті час (наприклад, "о 18:30").
  * Розбиття списку за комами ламає складні речення з підрядними частинами.
* **Відсутність локального збереження нотаток:**
  * У додатку немає локальної бази даних (Room / DataStore). При перестворенні екрана, повороті пристрою або повторному вводі результат попереднього аналізу втрачається.
* **Відсутність планувальника нагадувань у системі Android:**
  * Поле `has_reminder = true` лише відображається в UI картки. Системні сповіщення через `AlarmManager` або `WorkManager` не реєструються.

### 2. Технічний борг (Technical Debt)

* **Низькорівнева мережа без бібліотек:**
  * Використання ручного `HttpURLConnection` та ручного парсингу JSON через `JSONObject` замість сучасного стека (Retrofit/Ktor + Kotlinx.Serialization/Moshi).
* **Відсутність повноцінної архітектури Android (MVVM / MVI):**
  * Логіка виконання мережевого запиту (`callBackendApi`) та керування станом викликається безпосередньо з Composable-функції через `rememberCoroutineScope` замість відокремленого `ViewModel`.
* **Відсутність юніт- та інтеграційних тестів:**
  * Тести в `ExampleUnitTest.kt`шаблонні (`2 + 2 = 4`). Бекенд-ендпоінти та парсинг моделей Gemini не покриті автоматизованими тестами (`pytest`).
* **Монолітна структура бекенду:**
  * Моделі, контролери, логіка роботи з Gemini та fallback-рушій знаходяться в одному файлі `backend/main.py`

### 3. Ризики (Risks)

* **Залежність від зовнішнього API (Gemini Quota & Latency):**
  * Вичерпання безкоштовних лімітів запитів (Rate Limits / 429 Too Many Requests) або затримки відповіді понад таймаут клієнта (15 секунд) призводять до деградації досвіду користувача.
* **Несинхронізовані часові пояси:**
  * Час розраховується на основі системного годинника сервера (`datetime.now()`). Якщо часовий пояс сервера відрізняється від поясу пристрою користувача, дати нагадувань будуть розраховані зі зсувом.
* **Вразливість до Prompt Injection:**
  * Текст користувача без санітизації вставляється напряму у шаблон промпту. Спеціально сформований ввід може спробувати змінити формат відповіді або змусити модель обійти системні інструкції.
* **HTTP замість HTTPS у продакшені:**
  * Використання незахищеного протоколу передачі даних (`cleartext HTTP`) не підходить для публічного релізу та блокується політиками безпеки Android за замовчуванням поза локальною мережею.
