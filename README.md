# 🧠 MindNotes — AI-Powered Smart Note Organizer

**MindNotes** — інтелектуальний мобільний додаток для швидкої фіксації та автоматичного впорядкування думок. Додаток перетворює неструктурований сирий текст на охайні структуровані нотатки з автоматичною категоризацією, чеклістами завдань, розпізнаванням дедлайнів та локальним збереженням на пристрої.

> **Архітектурна концепція:** *«Користувач пише, AI структурує, користувач підтверджує та зберігає»*.

---

## 🚀 Ключові можливості

* **Швидка фіксація:** Введення вільного потоку думок без ручного вибору категорій чи форматування (від 3 до 2000 символів).
* **Автоматична категоризація:** Визначення категорії («Навчання», «Робота», «Покупки», «Особисте», «Плани», «Здоров'я») та лаконічного заголовка.
* **Розумне структурування:** Перетворення переліку справ на чекліст із маркерами `- [ ]` або розбиття тексту на логічні абзаци.
* **Виявлення дедлайнів:** Розпізнавання відносного часу («завтра о 15:00», «у п'ятницю») та перетворення його на точний час нагадування `YYYY-MM-DD HH:MM`.
* **Локальне сховище (Room SQLite):** Збереження підтверджених нотаток на пристрій із можливістю перегляду без інтернету.
* **Відмовостійкість (Fallback Engine):** Вбудований евристичний рушій на бекенді, який структурує нотатки навіть при відсутності інтернет-доступу до Gemini або API-ключа.

## 📱 Як користуватися додатком

1. **Введіть сиру думку:**
   * У текстове поле на головному екрані запишіть будь-які плани, завдання чи покупки.

2. **Надішліть на обробку:**
   * Натисніть кнопку **«Обробити через AI Backend»**.
   * Додаток відобразить індикатор завантаження під час аналізу.
3. **Перегляньте пропозицію AI:**
   * Ознайомтеся зі згенерованим заголовком, категорією, чеклістом та датою нагадування.
4. **Збережіть нотатку на пристрій:**
   * Натисніть кнопку **«💾 Зберегти нотатку»**.
   * З'явиться підтвердження збереження, а нотатка миттєво додасться до нижнього блоку **«📁 Збережені нотатки»**, де вона залишатиметься доступною навіть після перезапуску програми.

## 🛠 Технологічний стек

* **Mobile:** Android, Kotlin 2.2, Jetpack Compose, Material 3, Coroutines, Flow.
* **Local Database:** Room 2.7 SQLite + Google KSP2 (`com.google.devtools.ksp`).
* **Backend:** Python 3.10+, FastAPI, Pydantic, Uvicorn.
* **AI Engine:** Google Gemini 2.5 Flash (`google-generativeai`) + Fallback NLP-рушій.
